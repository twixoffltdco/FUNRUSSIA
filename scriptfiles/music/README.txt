========================================
  MUSIC SYSTEM - HOW TO ADD TRACKS
========================================

1. Radio: edit scriptfiles/music/radio.ini
   Format: Station Name=http://stream_url

2. Playlists: create scriptfiles/music/playlist_AnyName.ini
   Format: Track Name=http://mp3_or_stream_url

3. Save file -> open /music in game -> list is already updated.
   No reload command needed. No server restart needed.

4. Commands:
   /music  /radio  /musicgui  - open GUI
   /music stop                - stop

Passengers hear the same music as the driver.
